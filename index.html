HSCBS Font Banner

Type below, the preview updates live. Use [fill,border] to change colors from that point onward.

Color tags: [red,black], [#ff0000,#00ff00] or CSS names; leave a slot empty to keep it ([,blue]). Applies from that point on.
Letters sit 1px apart (shared border); a space is 3px of border colour, an underscore 1px. Capitals are used for letters missing in lowercase. Multi-line supported (each line keeps its own border; tick "stretch" to widen shorter lines to the longest).
Pixel data from pixelfont.json.
