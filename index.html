HSCBS Font Banner

Type below, the preview updates live. Use [fill,border] to change colors from that point onward.

Color tags: [red,black], [#ff0000,#00ff00] or CSS names; leave a slot empty to keep it ([,blue]). Applies from that point on.
Neighbouring borders merge into 1px when the merge options allow (Same colour = only if both borders match, otherwise 2px with 1px of each); a space is 3px of border colour, an underscore 1px. Capitals are used for letters missing in lowercase. Multi-line supported (tick "stretch" to widen shorter lines to the longest). Add {hs} or {vs} at the start of a line to stretch that line horizontally or proportionally (keeping letters square); these tags override the square-stretch checkbox for that line.
Pixel data from pixelfont.json.
